**Agent Assist (Salesforce Service Console Utility)** | *Salesforce Developer*
*An AI-powered real-time support application integrated into the Salesforce Service Console to enhance agent productivity during live customer interactions.*

*   **Real-Time Telephony Integration:** Engineered an event-driven LWC framework utilizing Platform Events (`VoiceCall__e`) and Lightning Message Service (LMS) to synchronize live Salesforce VoiceCall events with an external AI engine.
*   **Websocket Architecture & UI:** Developed complex Lightning Web Components (LWC) and a resilient websocket utility to manage bi-directional data flow, dynamically surfacing context-aware Knowledge Cards and Post Call Summaries (PCS).
*   **AI-Powered Features:** Implemented an interactive 'Ask Me Anything' (AMA) interface and a sentiment-aware live transcript viewer, reducing average handle time (AHT) and elevating customer support quality.
*   **Secure API & Telemetry:** Authored secure Apex integrations using OAuth 2.0 (Azure) for authenticated websocket sessions and integrated comprehensive Splunk telemetry to track agent engagement and drive UI optimizations.
